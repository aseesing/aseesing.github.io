u64_to_chars(value, buf):
zeros = count the leading zero bits of value
length = table[zeros], + 1 if value >= next power of ten
top = value / 10^16
both = value / 10^8 # beside the line above
high4 = 4 × (both − top × 10^8)
low4 = 4 × (value − both × 10^8)
top_length = table[length]
drop = table[length] # leading zeros to drop
store the top's characters at buf # from a table
 
digits16(high4, low4):
x = high4 and low4 in one 256-bit register
q = x / 40000 # the first four
rq = x + q × (2^18 − 40000) # the last four
spread each group of four over four lanes
lanes ÷ 1000, ÷ 100, ÷ 10, ÷ 1 # multiply-highs
tens = 10 × the lane before
digits = lanes − tens + '0'
pack the 16 lanes into 16 bytes
 
drop the leading zeros with a shuffle
store the 16 bytes at buf + top_length
return length
